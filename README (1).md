
# 📚 AI Study Assistant

An AI-powered study assistant developed using Python,
Streamlit, and Google Gemini API.

## 🚀 Features

- AI-powered question answering
- Beginner difficulty level
- Intermediate difficulty level
- Advanced difficulty level
- Simple explanations
- Key points
- Practical examples
- Quick revision
- Practice questions

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- Google GenAI Python SDK

AI-Study-Assistant/

├── app.py

## ⚙️ Installation

Install the required libraries:

pip install -r requirements.txt

## ▶️ Run the Application

streamlit run app.py

## 🔑 API Key

The application requires a Gemini API key.

The API key is entered by the user in the application
and is not stored in the source code.

Never upload your API key to GitHub.

## 🎯 How It Works

1. User enters a study question.
2. User selects a difficulty level.
3. The application creates a structured AI prompt.
4. The prompt is sent to Gemini.
5. Gemini generates the response.
6. The application displays the explanation,
   key points, example, revision notes and
   practice questions.
